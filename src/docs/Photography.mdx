# Photography

Real runs, shot on real days. Photos are black and white like the rest of the system — light, grain and place do the work. They sit beside the data, never behind it.

## Library

Drop files into `public/photos/` with these names — each slot fills in as soon as its file exists. Then update its `alt` in `src/data/photos.ts`.

## Treatment

- **Colour** — monochrome. `<Photo>` applies `grayscale(1) contrast(1.1)`; export already-converted files when you can.
- **Contrast** — deep blacks, clean whites. Don't crush detail in shoes or sky.
- **Grain** — keep it. At small sizes it reads like the system's LCD texture.
- **Crop** — subject off-centre, horizon low, room to breathe. The UI never overlays.
- **Alt text** — describe what's in it ("Runner crossing the Pfluger bridge at dawn"). Purely decorative photos (the share-card background) get `alt=""`.
