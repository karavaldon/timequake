## Principles

1. **Black and white first.** Like an LCD. Hairlines separate things; fills are rare.
2. **One action, one accent.** `bg/action` is the only filled button on a screen (black in light, Volt in dark). Mulberry and Volt mark what's live, actionable or in progress.
3. **Numbers are mono.** Every number is Chivo Mono. Readable mid-stride.
4. **Words are warm.** Serif headlines say valuable, nice things every day.
5. **Accessibility built-in.** Every color pair is audited (text 4.5:1, graphics 3:1); zones are labelled, not colour-coded; live targets are 72 px.

## What's here

- **Foundations:** Color (light and dark), Typography, Spacing & Shape, Photography.
- **Core:** Button, Text Field, Switch, Segmented Control, List Row, Tag, Photo, Top Bar, Bottom Nav, Sheet, Toast, Device Status.
- **Running:** Stat, Live Metrics, Route Map (offline SVG), Run Map (Mapbox, black and white from tokens), Line Chart, Bar Chart, Zone Bar, Splits Table, Run Row.
- **Screens:** Today, Live Run, Run Detail, Trends, Run Log, Devices. Each one is built only from the pieces above.
