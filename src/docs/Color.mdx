# Color

Mostly black and white, like an LCD. Separate things with **hairlines, not color fills**. Two lovely and vibrant accents: **Volt** is the one action and the live signal in dark mode; **Mulberry** carries the accent and live signal in light. Every intended pair passes WCAG 2.2 AA (`npm run audit:contrast`).

## Rules

- **One action.** `bg/action` is the only filled button on a screen.
- **Live means accent.** `text/live`, `icon/live` and `map/route-live` mark what's happening right now.
- **Zones are labelled.** `data/zone-1…5` is a single-hue ramp, so always show Z1–Z5 in text too.
- **Hairlines, not boxes.** `border/hairline` is decorative. Anything you can tap or type in uses `border/strong` or `border/input`, which reach at least 3:1.
